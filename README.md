# Vektereksamen — public documentation

Static HTML pages for the Vektereksamen iOS app, published with GitHub Pages.

- [Privacy policy](https://mboryczko.github.io/Vektereksamen/privacy.html)
- [Support and FAQ](https://mboryczko.github.io/Vektereksamen/support.html)
- [Use and purchases](https://mboryczko.github.io/Vektereksamen/terms.html)
- [Data deletion](https://mboryczko.github.io/Vektereksamen/data-deletion.html)

Norwegian Bokmål is the default. English pages have the `-en.html` suffix.

Publish from the `main` branch, `/ (root)`. No build, Jekyll, JavaScript,
web analytics, external fonts, or app source is required.
